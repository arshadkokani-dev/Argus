# ARGUS — Website Security Intelligence & DevSecOps Platform

**Tagline:** Always aware. Always ahead.

## Overview
ARGUS helps independent developers, freelancers, and small web agencies monitor website security, detect misconfigurations, understand risks with AI-assisted explanations, and verify fixes across scans.

## Core Workflow
`Detection → Understanding → Remediation → Verification`

## Tech Stack
- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Python, FastAPI, PostgreSQL, SQLAlchemy
- **Security:** Custom Passive Security Scanner, SSRF Protection, OWASP-aligned rules
- **AI:** Gemini / Groq Structured Remediation Assistant
- **DevSecOps:** Docker, GitHub Actions, Kubernetes (Minikube / kind)
